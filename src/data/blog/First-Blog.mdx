## Introduction

React's state management is one of the most fundamental concepts every developer needs to understand.

## How useState Works Under the Hood

When you call `useState`, React creates a closure that captures the current state value.

```javascript
const [count, setCount] = useState(0);
```

This is a simple example, but the internal mechanics are fascinating.
